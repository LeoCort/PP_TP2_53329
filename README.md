Este repositorio contiene la resolución del TP1. El proyecto fue desarrollado en Java utilizando IntelliJ IDEA y demuestra la implementación progresiva de conceptos de Programación Orientada a Objetos:
Uso de constructores y encapsulamiento.
Relaciones de asociación y composición (Evento, Sala, Actividad, Inscripción, Estudiante).
Aplicación de herencia y polimorfismo mediante clases abstractas (Actividad) y subclases concretas (Charla, Taller).

Ejecución:
Para probar el codigo, se debe ejecutar el método main de la clase App.java. En la carpeta de este archivo se adjunta el archivo salida_consola.png, el cual demuestra el funcionamiento exitoso del codigo.
